| # | Fix | Covers |
|---|---|---|
| P1 | **Job lifecycle safety.** Create the batch first; only after it succeeds store external_id AND set article statuses, in one `BEGIN IMMEDIATE…COMMIT`. If create raises: job → abandoned, no status change. Any open job with `external_id IS NULL` → abandoned. **Startup + every tick recovery:** for each kind with no open job, revert `copy_pending→themed` (copy_attempts−1), `check_pending→image_done`, `alcohol_pending→url_ok`. Pilot `run_now` uses the same recovery (no job row → pending reverted on restart). SIGTERM handler sets a stop flag checked between steps. | A1, A2, C1 |
| P2 | **Per-step isolation.** Each step (and each wave's steps) in its own try/except; `last_errors` in kv (step, error, time, consecutive count) → Summary "Last errors" rows. `write_reports()` always runs (finally, own try). **Per-step backoff:** after 3 consecutive failures of the same step, skip it for 10 → 30 → 60 min (stops repeated paid calls). | C2, A9, C5 |
| P3 | **API errors ≠ content failures.** `Anthropic(max_retries=6)`. API/transport errors (429/529/5xx, batch `errored`/`expired`/`canceled`) revert status without counting an attempt and never go into the "fix these problems" prompt; only lint/check verdicts count. If >50% of a batch is API errors: don't apply, abandon job, report. Alcohol "treated as alcohol" fallback only after 3 API failures for that title. | A8, C3 |
| P4 | **stop_reason check** on sync and batch results: anything but `end_turn` = API-type error (P3). max_tokens: alcohol 4,000, image check 4,000, copy 8,000, theme list 16,000. Summary row: count of `alcohol_reason LIKE 'check failed%'` (audit of the finished alcohol batch). | A7 |
| P5 | **Images.** Download + `save_crops` wrapped per prediction (bad/corrupt → prediction failed, article → copy_done, counts as image attempt). `succeeded` with no output → failed. Not finished after 30 min → `predictions.cancel` + failed. Missing image file at check → article back to copy_done; at upload → article error with reason (never crashes the wave). Polling continues while paused. | A3, A6, C4, A10, B11, C9 |
| P6 | **Themes.** Save each finished assignment chunk in kv (never re-paid).
